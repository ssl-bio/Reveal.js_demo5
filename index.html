Custom colors

  • Each Reveal.js theme defines at least 3 common colors:
    • Color for links: --r-link-color
    • Color for the background: --r-background-color
    • Color for the text: --r-main-color
  • These were used to generate a palette of colors with the help of the chroma.js library
  • The color palette was made broadly available by including them in the theme section of the custom css file (base.css)

Description of theme-based palette

  • The palette contains gradients, combinations and related colors to those above.
    • Gradients:
      • Link and Background colors: grad-LinkBg
      • Link and Main colors: grad-LinkMain
      • Main and Background colors: grad-MainBg
      • Dark and Light versions of the Link color: grad-Link
    • Related to Link color: (relative to the color wheel)
      • Analogous colors at ±15, ±30 and +5 degrees: ana-A
      • Analogous colors at ±45, ±60 and +65 degrees: ana-B
      • Analogous colors at ±75, ±90 and +105 degrees: ana-C
      • Opposite colors at ±120, ±150 and 180 degrees: opp-Link=
    • Combinations: At different percentages of the 2nd color: 12.5%, 25%, 37.5%, 50% and 62.5%
      • Link and Background colors: mix-LinkBg
      • Link and Main colors: mix-LinkMain

Use the palette to customize the theme

  • The slide below provides an interactive palette and controls for customizing the background boxes. Controls to select one of the boxes, as well as the opacity of the color are at the top right.
  • Preview of each box is displayed along with the color and opacity values
  • A preview of how the slide would look is at the bottom right.
    • Change the theme to see the effect of the selected settings on other themes.
    • Once satisfied with a set of values these can be applied to future presentations by setting two tailwind utilities (@utility bg-outer-box and @utility bg-inner-box) in the base.css file.
